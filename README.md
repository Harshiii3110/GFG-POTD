## Purpose

This repository contains solutions to GeeksforGeeks Problem of the Day challenges. It serves as a dedicated space to practice coding regularly, improve problem-solving skills, and maintain consistency.

## Goal

* Solve the GeeksforGeeks Problem of the Day on a regular basis.
* Strengthen logical thinking and coding proficiency.
* Build a consistent problem-solving habit.
* Track progress through GitHub.

* Python, C, Java
